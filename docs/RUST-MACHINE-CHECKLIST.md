# Rust 真机实测清单

本清单记录尚未实测的边界。只在朋友专用机器或用户另行授权的环境操作；本机真实 Codex、VS Code、配置、桌面和注册表不属于本轮测试范围。使用测试账号和假 API 密钥。保存安装包 SHA、`/api/runtime`、操作起止时间和诊断导出；不能仅凭接口返回成功打勾。

| 项目                   | 操作步骤                                                                                                                         | 观察与通过条件                                                                                                                                      | 要保存的证据                                                                                                                                                                                                            |
