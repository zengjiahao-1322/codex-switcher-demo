# Codex Switcher 0.1.5 Demo

从 VS Code 状态栏切换本机或 SSH 服务器的账号与 API，自动保存最近 10 份配置备份，并在额度不足时手动一键换到备用账号。支持 Windows、Mac Apple Silicon 和 Intel。

## 本版更新

- **编辑器快捷切换**：点击 VS Code 右下角的“Codex Switcher”，选择官方账号或自定义 API，确认后切换。本机窗口修改本机，SSH 窗口修改对应服务器；列表先显示加载状态，操作结果通过通知显示。
- **配置自动备份与恢复**：切换器改写本机配置前保存副本，相同内容不重复保存，只保留最近 10 份。在“设置 → 配置备份”选择恢复，确认后先保存当前配置，再按正常流程重启或重载共用窗口。副本不包含 `auth.json` 登录文件，恢复配置不会回滚账号登录。
- **额度不足一键换号**：额度提醒直接提供有余量的备用账号，确认后切换。快捷列表优先展示额度充足的账号，始终由用户手动发起。
- **操作来源日志**：诊断日志记录切换来自网页、本机编辑器或 SSH 编辑器，方便排查多窗口操作；敏感字段在记录前脱敏。

## 下载与安装

| 平台或扩展        | 文件                             | 用法                                                            |
| ----------------- | -------------------------------- | --------------------------------------------------------------- |
| Windows x64       | `codex-switcher-windows-x64.zip` | 完整解压，打开 `Codex Switcher/Start.cmd`，或运行 `install.cmd` |
| Mac Apple Silicon | `codex-switcher-macos-arm64.zip` | 运行 `Install.command`，或打开 `Codex Switcher.app`             |
| Mac Intel         | `codex-switcher-macos-x64.zip`   | 同上                                                            |
| 本机伴随扩展      | `codex-switcher-companion.vsix`  | 在本机编辑器安装并重载已有窗口                                  |
| 远端代理          | `codex-switcher-remote.vsix`     | 在“远程服务器”页更新，或安装到 Remote-SSH 服务器侧              |

五个下载都附有 SHA-256 校验文件。桌面包内置 Node.js 和依赖；应用、伴随扩展和远端代理均为 `0.1.5`，请配套使用。请先安装 Codex 桌面版或 OpenAI 官方 Codex 编辑器扩展。

## 从旧版本升级

**0.1.4 用户可在页面点击“检查更新”升级到 0.1.5。** 升级后在“编辑器与诊断”点击“一键更新扩展”，再到“远程服务器”页更新远端代理。旧代理版本不同会提示需要更新。

0.1.3 的更新地址固定在旧版本，需要手动下载安装本版一次。更新时保留原账号数据目录：Windows 解压版保留 `private/`，安装版运行新安装器；Mac 运行新包的 `Install.command`。自定义数据目录继续沿用原路径。开发目录通过 Git 更新。

配置备份保存在本机数据目录，使用相同的目录权限；它保存配置原文，不包含账号登录文件。恢复转换模式的配置需要原 API 配置仍存在，原配置已删除或改名时会说明原因。

升级及切换可能中断运行中的 Codex 任务，请先保存工作。已保存的聊天文件保留，运行中任务和未保存状态不能保证恢复。使用启动器打开的地址建立本机会话；后台重启后请重新运行启动入口。

## 平台验证与功能边界

发布流程在 Windows、macOS Apple Silicon 和 Intel 运行回归、浏览器入口、额度界面、安装包解压启动及真实 VS Code 多窗口检查；六项全部通过后才上传下载。Mac 另检查系统 Bash 安装、重复安装、数据保留、签名完整性与 LaunchServices 启动。

自动化检查使用隔离配置，不能代替具体设备的官方登录、额度和 Remote-SSH 服务器实际请求验证。远程功能仅支持 Remote-SSH、文件存储的官方登录及已确认可直连且有密钥的 API；WSL、容器和远程配置多份备份暂不支持。Cursor、Windsurf 和 Insiders 仍需在对应版本上人工验证。

Mac 应用使用 ad-hoc 签名，尚无 Apple Developer ID 签名或公证；首次打开可能需要在“系统设置 → 隐私与安全性”允许。包编译目标为 macOS 12+，CI 在 macOS 15 验证。

若操作失败，可在“编辑器与诊断”导出脱敏日志。日志仅保存在本机，不自动上传。

## 更新（本次替换）

- **服务器切换不再断开 SSH**：只重启服务器上的扩展，约 20 秒恢复，窗口和终端保留。
- **更新远端代理后自动生效**：页面会显示是否已切到新版。
- **服务器连接状态更准确**：连接不稳时显示“服务器连接中”，不再误报未检测到窗口。
- **失败原因更清楚**：切换确认超过 2 分钟会如实记为失败；更新检查失败时提示具体的系统代理。
- **续费后不再误报到期**：套餐优先读取实时额度信息，订阅日期尚未更新时会说明。
- **恢复备份后模型列表正确**：按恢复的来源和模型重新生成列表。
- **旧远端代理会提示更新**：升级旧代理时 SSH 会重连一次，之后切换只重启服务器扩展。
