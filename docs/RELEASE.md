# Codex Switcher 0.1.7 测试版 1 候选

0.1.7 测试版 1 候选：Claude Code 也能一键切换，并适配 Codex 桌面版 0.166 对旧对话的新限制。测试版，可能有问题。

- 选中 API 配置后点「用于 Claude Code」，即可让 Claude Code（命令行、VS Code 和桌面版 Code）使用这个 API；随时可点「恢复官方」。
- 只支持 OpenAI 协议的 API 也能给 Claude Code 用：经本机转换，使用期间需保持切换器运行。
- 远程服务器页也能为服务器上的 Claude Code 切换和恢复官方；需先在该页更新远端代理。
- 系统代理连不上 GitHub 时，检查更新会自动改为直连；代理地址里的账号密码不会写进日志。
- 新版启动时会接管仍在运行的旧版切换器。
- 切换会重启 Codex 桌面端，切换前会先提醒，避免打断正在运行的任务。
- 伴随扩展与切换器版本不一致时会提示更新；升级后请在「编辑器与诊断」点「一键更新扩展」。
- 官方服务报错时，诊断记录会保留隐去敏感信息后的原文，便于排查。

已知问题：Codex 桌面版 0.166 起，每条对话绑定到它所属的来源，不能直接在其他来源下继续。在官方账号和第三方 API 之间切换时，部分旧对话可能留在原来源，切换会提示「已保留在原来源」，切回原来源即可继续。官方问题见 openai/codex#58865。
