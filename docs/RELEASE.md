# Codex Switcher 0.1.7 测试版 1 候选

0.1.7 测试版 1 候选：修复切换前桌面重启提醒并保留脱敏的官方错误原文。测试版，可能有问题。

- 一键更新后，扩展、CLI 和 MCP 能立即找到新版本。
- 程序和快捷方式有了图标。
- 新版本首次启动时，如果桌面快捷方式不见了会自动补上；卸载重装后也会重新创建。
- 账号页按官方账单状态显示：优惠或试用结束日、下次账单、计划变更、不续费和付款异常。优惠期内的下次账单可能是 0 元。
- 修复 Codex 新版压缩旧对话后，切换时同步旧对话失败的问题。
- 未使用的官方账号会在登录到期前 2 天内自动续期，登录失效时可在切换页直接重新登录。
- 账号页把刷新额度和续期登录分开，并显示下次自动续期时间。
- 手动检查更新时会立即联网检查。
