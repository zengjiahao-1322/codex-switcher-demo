# Codex Switcher 0.1.7 测试版 3 候选

0.1.7 测试版 3 候选：新增用量统计，按账号和 API 显示 token 与估算费用；Claude Code 经本机转换时改为逐字显示。测试版，可能有问题。

- 新增“用量”分页：按来源统计 Codex 和 Claude Code 的 token 与估算费用。来源细分到每个官方账号、每个 API，带逐条请求记录，可以按来源、模型、结果筛选。
- 用量只读本机会话记录里的用量、时间、模型和错误类型，不读对话内容；打开分页时才建立索引，不常驻后台。
- 价格自动同步 OpenRouter 上 OpenAI、Anthropic、Google 等官方厂商的价格。每个 API 可以在“API 配置”里设为按官方价、按倍率（可选人民币）或不计费，也可以填网关自己的用量面板地址。官方账号显示为订阅折算，不是实际扣费。
- 经本机转换给 Claude Code 使用时，回复改为逐字显示。
- Codex 桌面版 0.167 起，不再接受被移到别的来源的对话。切换时，这类对话一律留在原来源，切回去就能继续，切换也更快；同一来源下换 API 或模型照旧。
- 修复一键更新后新版本启动时多等约 3 秒。
- 修复 Codex 桌面版的辅助进程被显示成第二个桌面端。
- 0.1.3、0.1.4、0.1.5 这几个早期 Node 版已从发布页下架，建议直接下载最新版安装。
- 伴随扩展的版本随切换器更新。升级后请在“编辑器与诊断”点“一键更新扩展”。

已知问题：
- 用量统计看不到首字延迟、TPS，也看不到网关内部用的是哪个号，这些请在网关自己的面板里看。
- 远程功能仍未在真实的 Remote-SSH Linux 服务器上验收；macOS 版只经过自动化验证，没有实机测试。
