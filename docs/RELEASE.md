# Codex Switcher 0.1.7 测试版 2 候选

0.1.7 测试版 2 候选：重做了 Claude Code 切换，Codex 和 Claude Code 分开管理，各自显示正在使用的来源。测试版，可能有问题。

- 页面顶部可以在 Codex 和 Claude Code 之间切换，两边分别显示当前在用什么，互不影响。
- Claude Code 页按 Claude Code 的接入方式列出 API：Anthropic 协议的直连，OpenAI 协议的经本机转换。缺少密钥的 API 会置灰并注明原因。
- 可以给 Claude Code 单独设置快速模型，供后台小任务和 Haiku 别名使用，不再和主模型共用。
- 新增「检测连接」：按 Claude Code 实际走的路径发一条最短的请求，并区分是连不上，还是上游返回了错误。
- 修改 Claude Code 正在使用的 API 的地址或密钥后，会自动同步到 Claude Code。
- 选用需要转换的 API 时，不再自动开启开机自启，改为提示，由你决定是否开启。
- 「恢复接管前的配置」会如实恢复：如果接管前用的是别的网关，就恢复成那个网关。
- Claude Code 的配置文件被手动改坏时，页面会给出提示，不再无法打开。
- 上次异常退出后再次打开切换器，不再多等约 2 秒。
- 恢复配置备份时，只有确实会重启 Codex 桌面端才会先提醒。
- 伴随扩展的版本随切换器更新。升级后请在「编辑器与诊断」点「一键更新扩展」。

已知问题：
- Codex 桌面版 0.166 起，每条对话绑定到它所属的来源，不能直接在其他来源下继续。在官方账号和第三方 API 之间切换时，部分旧对话可能留在原来源，切换会提示「已保留在原来源」，切回原来源即可继续。官方问题见 openai/codex#58865。
- 经本机转换给 Claude Code 使用时，回复是整段返回，不会逐字显示。
