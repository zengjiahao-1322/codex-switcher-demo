# Codex Switcher 0.1.7 测试版 4 候选

0.1.7 测试版 4 候选：切换来源时保留 Codex 桌面端的侧边栏项目；修复应用内一键更新失败；移除旧版 Node 后台。测试版，可能有问题。

- 新版 Codex 桌面端按 ChatGPT 账号分开保存侧边栏项目，切到 API 时侧边栏会变空。现在切换来源时，所有来源共用同一份侧边栏。设置里可以关掉；关掉后恢复官方按账号分开的方式。
- 修复应用内一键更新报 os error 31、更新失败。
- 切换器只剩原生后台：旧版 Node 后台、旧版升级桥和在线安装器都已移除，安装包更小。
- 出错时提示里写明是哪个文件、哪一步，方便排查。
- macOS 版每个架构都经过真实安装包的自动验收：安装、启动、命令行、MCP、钥匙串登录，以及从 0.1.7 测试版 3 一键升级。

已知问题：
- 从测试版 3 升级后，切换器会先用随机端口运行，退出后重新打开一次即恢复固定端口。
- 在切换器里卸载前，请先从托盘菜单退出 Codex 桌面端（关窗口只会藏到托盘），卸载才能还原侧边栏规则。手动运行卸载脚本或在 Mac 上用脚本卸载时不会还原。
- 用量统计看不到首字延迟、TPS，也看不到网关内部用的是哪个号，这些请在网关自己的面板里看。
- 远程功能仍未在真实的 Remote-SSH Linux 服务器上验收；macOS 版没有实机测试。
