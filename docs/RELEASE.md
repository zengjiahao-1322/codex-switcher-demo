# Codex Switcher 0.1.7 测试版 6 候选

0.1.7 测试版 6 候选：账号额度里显示官方的“用量上限重置”次数和过期时间，可以直接在切换器里用掉一次。测试版，可能有问题。

- 新增：官方账号的额度里显示可用的重置次数，以及每次重置的过期时间；账号列表里显示最早哪天到期。
- 新增：可以在切换器里用掉 1 次重置，会先用最早过期的那次。使用前会提示：额度立即恢复，下次周限额重置时间会改为你下次在 Codex 里发消息后的 7 天。
- 当前正在用的账号如果登录快要由 Codex 自己续期，会暂时不让重置，避免把正在用的登录顶掉，稍后再试即可。
- 每次重置的结果（成功、被拒绝、失败的原因）都会写进诊断日志，出问题时导出诊断日志就能看到。
- 显示和使用重置需要 Codex 0.167 及以上（新版桌面端或官方扩展自带）；版本太旧时不显示次数。

已知问题：
- 手动运行卸载脚本或在 Mac 上用脚本卸载时，不会还原侧边栏规则。
- 用量统计看不到首字延迟、TPS，也看不到网关内部用的是哪个号，这些请在网关自己的面板里看。
- 远程功能仍未在真实的 Remote-SSH Linux 服务器上验收；macOS 版没有实机测试。
