# Codex Switcher 0.1.7 测试版 5 候选

0.1.7 测试版 5 候选：修复端口被占用时“经本机转换”的 API 切换失败，以及部分电脑切换时报 os error 32；用量页显示 Codex 的自动重试和后台调用；伴随扩展随切换器自动更新。测试版，可能有问题。

- 修复：切换器的常用端口被别的程序占着时，会改用其他端口运行，但“经本机转换”的 API 仍去找原端口，切换一直报“本机转换服务未运行”。现在转换服务会跟着用新端口；已有配置正在用原端口时保持不动，并提示退出切换器后重新打开。
- 修复：部分电脑上切换 API 时报“另一个程序正在使用此文件 (os error 32)”。切换前检查配置用的临时文件夹一时删不掉（常见于杀毒软件正在扫描），以前会让整个切换失败，现在不影响切换。
- 用量页显示 Codex 自己的自动重试、上游返回的错误（如 500、429）和后台调用（如记忆功能），和网关记录对得上。后台调用没有 token 数，不计入费用。
- 切换器升级后，已装过伴随扩展的编辑器会自动换上新版扩展，不用再点“一键更新扩展”；那个按钮只在还留着旧版时出现。
- 在切换器里卸载时，会先关闭 Codex 桌面端再还原侧边栏规则，不用先从托盘退出。
- 开机自启只由你在设置里打开，切换到“经本机转换”的 API 时不再自动开启。
- 去掉了“刷新运行状态”和“更新价格”两个按钮：编辑器状态本来就会自动刷新，价格簿过期后也会在后台自动更新。

已知问题：
- 手动运行卸载脚本或在 Mac 上用脚本卸载时，不会还原侧边栏规则。
- 用量统计看不到首字延迟、TPS，也看不到网关内部用的是哪个号，这些请在网关自己的面板里看。
- 远程功能仍未在真实的 Remote-SSH Linux 服务器上验收；macOS 版没有实机测试。
